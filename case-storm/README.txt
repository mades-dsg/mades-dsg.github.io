CASE STORM — симулятор открытия кейсов CS2
==========================================

Баланс виртуальный: пополнить его деньгами, вывести скины или деньги нельзя.

ЧТО ВНУТРИ
  index.html   — весь сайт одним файлом (можно открыть двойным кликом)
  server.js    — сервер для чата, реального онлайна, live-ленты и батлов с живыми людьми
  source/      — исходники (js, css, build.py)

КАК ЗАПУСТИТЬ С ЖИВЫМИ ИГРОКАМИ
  Если открыть index.html просто двойным кликом, работает всё, кроме чата, онлайна и батлов:
  без сервера других людей на сайте нет, а ботов больше нет.

  1. Установи Node.js 18+ (https://nodejs.org).
  2. Положи server.js и index.html в одну папку.
  3. В этой папке выполни:  node server.js
  4. Открой http://localhost:3000. Друзья в той же сети заходят на http://<твой-IP>:3000.

  Чтобы сайт был доступен всем в интернете, залей папку на любой хостинг с Node.js
  (Render, Railway, Fly.io, свой VPS). Команда запуска — node server.js,
  порт берётся из переменной PORT.
  Если страница лежит отдельно от сервера, впиши адрес сервера в Настройках сайта.

ЦЕНЫ
  Цены — снимок Steam Community Market на 2026-10-18 для каждого износа, StatTrak ≈ ×1.28.
  Валюта переключается в настройках (₽ / $ / €), курс подтягивается автоматически.
